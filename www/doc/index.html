Release Notes

The current release is 4.0.1. It is available from ACS package repository.

Permissions

If you install the package as site-wide admin, you have full permission for any function in news. If you are the site-wide admin and want somebody else to do the news administrator, assign him/her the privilege 'news_admin' in /permissions/. If you are not the site-wide admin, you must ask the latter to do so.

Markdown image paste

In News 6.0.0d3 or newer, clipboard image uploads are controlled by the package instance parameter AllowImagePasteP, which defaults to 0 (disabled). To enable them for this News instance:

  1. Install and enable Attachments 0.14.2 or newer and install richtext-markdown 0.1d3 or newer.
  2. Set the News instance parameter RichTextEditor to markdown and AllowImagePasteP to 1.
  3. Select HTML as the article's content format to use Write/Preview. The Markdown Text format is a separate content format.

The image-paste setting does not activate the editor, and enabling site-wide richtext editing is not required. Authors still need the existing News creation or administration permissions.

Pasted PNG, JPEG and GIF images are staged privately for Preview, then attached to the article item when saved. They remain available across revisions and are deleted with the article. Delivery supports responsive resized variants through the shared Attachments image cache and preserves the originals. No child mount or File Storage mapping is required.

Disabling AllowImagePasteP prevents new uploads and saving staged images, including from already open editor forms. Existing attached images remain viewable. Other content formats remain available.
